# AI Productivity Hub

Build VXK_Assistant AI, a clean, modern, and professional AI productivity web app.

Features to include:
1. Responsive Sidebar Navigation:
   - Dashboard (Overview)
   - AI Task Planner
   - Email Generator
   - Meeting Summarizer
   - Mobile collapsible drawer navigation

2. Dashboard View:
   - Productivity overview cards (tasks completed, pending action items, active projects)
   - Today's Tasks list with completion toggles
   - Upcoming Deadlines widget
   - Quick launch cards/buttons directly opening each of the 3 AI tools

3. AI Task Planner:
   - Input form for tasks with priority and deadlines
   - AI generation action with loading states
   - Generates a prioritized breakdown and a clear, structured daily schedule with time blocks

4. Email Generator:
   - Input for email topic/key points
   - Tone selector (Formal, Friendly, Professional, Concise)
   - AI output preview with copy-to-clipboard, edit capability, and subject line generation

5. Meeting Summarizer:
   - Paste notes input area with sample template button
   - AI output generating executive summary, extracted action items with owners & deadlines, and key decisions

6. General & Polish:
   - Realistic demo/mock AI generation with smooth loading state animations and realistic outputs
   - Preloaded sample data so it looks great and presentation-ready immediately
   - Prominent Responsible AI disclaimer notice: 'AI can make mistakes. Please verify important details and review outputs.'
   - Polished, accessible UI using sleek cards, crisp typography, and badge indicators
